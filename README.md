Интерактивное CLI-приложение для управления бюджетами и транзакциями, разработанное на TypeScript.

## Возможности

- 📊 Просмотр всех счетов с балансом
- ➕ Создание новых счетов
- 👁️ Просмотр детальной информации по счёту
- 💰 Добавление транзакций (доходы и расходы)
- 🗑️ Удаление транзакций
- 🗑️ Удаление счетов
- 📥 Экспорт транзакций в CSV-файлы
- 🔄 Удобная навигация между меню

## Установка

```bash
npm install
```

## Сборка

```bash
npm run build
```

## Запуск

```bash
npm start
```

## Использование

После запуска приложения вы увидите главное меню со списком всех счетов. Вы можете:

1. Выбрать счёт для просмотра деталей
2. Создать новый счёт
3. Выйти из приложения

В меню счёта доступны следующие действия:

- Добавить транзакцию (с указанием суммы, типа, даты и описания)
- Удалить транзакцию
- Экспортировать все транзакции в CSV-файл
- Удалить счёт
- Вернуться к списку счетов

## Технологии

- TypeScript
- Node.js
- Inquirer.js (для интерактивного CLI)
